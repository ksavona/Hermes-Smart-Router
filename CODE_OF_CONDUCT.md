# Code of Conduct

## Our Standard

This project expects respectful, technically focused collaboration.

Participants should:
- communicate clearly and in good faith
- focus criticism on code, behavior, and evidence
- avoid harassment, abuse, insults, and intimidation
- respect maintainers' scope and licensing decisions

## Unacceptable Behavior

Unacceptable behavior includes:
- personal attacks
- harassment or discrimination
- threats or intimidation
- bad-faith issue spam or disruptive conduct
- publishing private information without consent

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or block participants whose behavior harms the project or its community.

## Reporting

Use GitHub Issues only for technical project matters.

For conduct concerns, contact the repository owner directly through GitHub.
